# FTP — File Transfer Protocol

## Description

Projet universitaire de programmation réseau consacré au transfert de fichiers entre deux machines à travers une connexion TCP.

L'objectif est de comprendre le fonctionnement d'une architecture client-serveur et les mécanismes de communication utilisés pour échanger des données sur un réseau.

## Objectifs pédagogiques

- Comprendre le modèle client-serveur.
- Étudier les communications à travers le protocole TCP.
- Manipuler les échanges de données entre machines.
- Comprendre le fonctionnement du transfert de fichiers.
- Mettre en pratique les notions de programmation réseau.

## Fonctionnement général

Le protocole FTP (File Transfer Protocol) permet de transférer des fichiers entre un client et un serveur.

Il s'appuie sur TCP pour assurer une communication fiable et ordonnée.

Le fonctionnement repose sur deux composants :

- **Serveur :** reçoit les connexions et traite les demandes du client.
- **Client :** établit une connexion avec le serveur et demande des opérations de transfert.

Le protocole FTP classique distingue une connexion de contrôle et une connexion de données.

## Concepts abordés

- Architecture client-serveur
- Protocoles TCP/IP
- Connexions réseau
- Transmission de données
- Gestion des échanges et des erreurs
